# TaskTrack Pro

Ứng dụng quản lý công việc xây dựng bằng React, Vite và Tailwind CSS.

## Tính năng

- Thêm, sửa, hoàn thành và xóa công việc.
- Phân loại ưu tiên, đặt hạn chót, tìm kiếm và lọc công việc.
- Xem thống kê, lưu dữ liệu trên trình duyệt và chuyển giao diện sáng/tối.

## Chạy ứng dụng

```bash
npm install
npm run dev
```

## Lệnh khác

```bash
npm run build
npm run preview
npm run lint
```

Dữ liệu công việc được lưu trong `localStorage` của trình duyệt hiện tại.
